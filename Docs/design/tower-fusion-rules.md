# Tower Fusion Design Rules

ClickToDestroy のタワー合成システムに関する設計ルールと決定事項。
タワーの追加・調整時はこのドキュメントを優先する。

## 合成ティアと役割

合成回数が増えるほど性能の振れ幅が大きくなる代わりにコスパが悪くなる。

| ティア | 役割 | スキル数 | コスト感 |
|---|---|---|---|
| 単体（合成なし） | 最低限の仕事をこなす | 0 | 安い |
| 2-fusion | **メインとなるタワー。基本はこれを運用していく** | **1** | 標準 |
| 3-fusion | 尖った性能を持つ。刺さる時は強いが、使い方を間違えると役に立たない | **2** | やや高い |
| 4-fusion | 器用万能。一つでルートをほぼ完全に防げるが**コスパは悪い** | TBD | 高い |

## 基本タワー（合成元）の役割

| タワー | 攻撃属性 | 主な特徴 |
|---|---|---|
| 兵士タワー | （兵士の物理） | タワー本体は攻撃しない。雑魚に勝てる程度の兵士を排出して足止め |
| 弓矢タワー | 物理 | 低威力・高頻度・広射程。空中対応 |
| 魔法タワー | **魔法（唯一）** | 高威力・中頻度・通常射程。空中対応 |
| 砲台タワー | 物理 | 高威力・低頻度・**範囲攻撃**。空中**不可**だが範囲内ならダメージ |

## 特殊な行の解釈

### 3F-3 聖者（攻撃しないサポートタワー）

- `属性 / 威力 / 頻度` はすべて `なし`
- `範囲攻撃 = 範囲` は **バフ効果の半径** を意味する（攻撃範囲ではない）
- `空中対応 = 不可` は「空中の敵にバフ・回復を与えない」の意ではなく、攻撃しないので適用外
- 実装時はサポート系専用のフィールド（`buffRadius`、`healPerSecond` など）を別途用意する

### 2F-2 聖騎士の属性表記

- **基本攻撃は物理**
- スキル「魔法の範囲攻撃」**発動時のみ魔法属性**になる
- `属性` 列は基本攻撃の属性を記述（スキル発動時の一時的属性は反映しない）

## スキル設計ガイドライン

### スキル数のルール

- 単体タワー: 0 個
- 2-fusion: **1 個**
- 3-fusion: **2 個**
- 4-fusion: TBD

### スキルの種類（参考分類）

- **パッシブ**: 自動で常時発動する効果（例: 2F-1 忍者の回避、2F-6 地震発生機の地形）
- **確率発動**: 通常攻撃時に確率で発動（例: 2F-2 聖騎士の魔法範囲攻撃）
- **アクティブ**: クールダウン管理で時々発動する効果（例: 2F-4 大地の魔法使いの魔力暴走）
- **デバフ付与**: 攻撃した敵に状態異常を与える（例: 2F-4 の魔法防御低下）
- **召喚系**: ユニットを生み出す（例: 3F-1 ゾンビの召喚、復活）
- **サポート系**: 味方に効果を与える（例: 3F-3 聖者の回復・バフ）

### 2-fusion と 3-fusion の差別化

両ティアともスキルを持つが、規模で差を付ける:

- 2-fusion のスキルは **軽め**: 基本性能の延長線上にある効果
- 3-fusion のスキルは **重め・尖り**: 単独では無意味だがハマると強い効果（バフ、CC、デバフ、ランダム性のある超火力）

## CSV 列の意味

[`tower-fusions.csv`](./tower-fusions.csv) の列定義。

| 列 | 値 | 補足 |
|---|---|---|
| `ティア` | `2-fusion` / `3-fusion` / `4-fusion` | |
| `ID` | `2F-1` 〜, `3F-1` 〜 | 実装時の参照キー |
| `親1` 〜 `親3` | `兵士` / `弓` / `魔法` / `砲台` | 順不同。2-fusion は `親3` 空欄 |
| `名前` | 表示名 | |
| `属性` | `物理` / `魔法` / `なし` | 基本攻撃の属性 |
| `威力` | `低` / `中` / `高` / `なし` | |
| `頻度` | `低` / `中` / `高` / `なし` | |
| `範囲攻撃` | `単体` / `小範囲` / `範囲` | 聖者の場合はバフ範囲 |
| `空中対応` | `可` / `不可` | |
| `兵士排出` | `有` / `無` | |
| `役割` | テキスト | スキル説明込み |

実装値が定まったら、`威力` / `頻度` は実数値に置き換える、または別列 (`damage`, `interval_sec`) を追加する想定。
